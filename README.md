# English Practice — EduCourse

Cuestionario interactivo para repasar el curso de inglés de EduCourse, organizado por semanas y temas.

- **Semana 1:** números, lugares, puntuación y deletreo.
- **Semana 2:** días, meses, pronombres, futuro con *will*, Wh- questions, daily routine, artículos (a / an / the) y transition words.
- **Semana 3:** estaciones y clima, preposiciones de lugar y de tiempo (in, on, at), frutas, vegetales y repaso de transition words.

Es una sola página estática (`index.html`), sin dependencias ni build.

## Uso local

Abre `index.html` en el navegador.

## Agregar preguntas

Las preguntas están en el arreglo `BANK` dentro de `index.html`. Cada pregunta indica su semana (`week`) y su tema (`cat`); los temas de cada semana se definen en `WEEKS`.

## Despliegue

Publicado con GitHub Pages desde la rama `main` (carpeta raíz).
